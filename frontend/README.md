# canilarpit

Can you larp it, and for how long?

```bash
npm run dev
```

Vite + React + React Router. `src/data.ts` holds the entries; everything else reads from it.

Built: `/` (home) and `/entry/{slug}`, plus `/category/{slug}`. `/spot-the-larper`,
`/just-learn-it`, and `/stats` render a placeholder.
